# Theme: Compute follows the sun

Routing compute to the cheapest, cleanest power.

## Idea: A learning modular prediction engine

Put data, equations, and visualizations into markdown files. The markdown files model the state of the world based on data, assumptions, and predictions. Then an engine can run casestudy simulations, live data collection, live prediction modeling, live tuning, and retrospective testcase analysis.

### Goals

- Generate actionable UX, intuition development, or high quality data. Facilitate experimentation, regression testing, live system monitoring, trend visualization, actionable cause analysis for improvement or regression, and extensibility to test out new ideas.
- Optimize for human oversight and Agentic interaction and prototyping.
- Prioritize moving arithmetically moving compute to cheaper electricity. Secondary, visualize, track, or optimize carbon consumption.
- Start with highlevel abstractions, and stochastic analysis. Then as pragmatic progress into actual entity simulation.
- Always have a working prototype.
- Contents of markdown files act as all the raw data and editable values and configuration.
