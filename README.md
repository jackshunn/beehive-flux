# Beehive Flux

A Utah Hard Tech Week 2026 hackathon project for the [Torus](https://www.torus.co/) bounty category.

## Summary

Compute follows the sun. Beehive Flux models the world as editable markdown (power, weather, workloads, and the links between them), then simulates, predicts, and learns where and when compute should run to meet the cheapest, cleanest energy.
